description: Revisar issues [SC-AUTO] antes de tocar Website o SEO
---
Antes de cualquier cambio de Website o SEO en Impulsa Lab, lista los issues abiertos de GitHub con label `SC-AUTO` (usa `gh issue list --label SC-AUTO --state open` o el MCP de GitHub). Resume cada uno y marca los que sean bloqueadores para el cambio que se va a hacer. No edites código de Website/SEO hasta revisarlos. (Regla de comportamiento #7.)
