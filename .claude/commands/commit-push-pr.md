Revisa `git status` y `git diff`. Escribe un mensaje de commit estilo conventional-commits (`feat:`/`fix:`/`docs:`/`chore:`) que describa el cambio de forma concisa. Haz `git add -A`, commit y `git push` a la rama ACTUAL.

Si la rama actual es `main-clean`, confirma con el usuario antes de pushear.

Cierra con un resumen de una línea de lo que se envió (archivos + propósito). No afirmes que el push tuvo éxito sin ver la salida real del comando.
